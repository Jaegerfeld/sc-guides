# Star Citizen Guides

Inoffizielle Feldhandbücher zu Star Citizen (DE/EN), als statische HTML-Seiten mit PDF-Download.

- **Einstieg:** `index.html` (veröffentlicht über GitHub Pages)
- **PDF-Downloads:** Ordner `pdf/` (je Guide DE und EN, dazu eine ZIP mit allen)

Hinweis: Die Community-Karten einiger Guides sind derzeit nicht enthalten (Rechteprüfung läuft); sie werden nach und nach ergänzt oder ersetzt.

*Inoffiziell, nicht mit Cloud Imperium Games verbunden. Star Citizen® ist eine Marke von CIG. Alle Angaben ohne Gewähr; Spieldaten sind patch-abhängig.*
